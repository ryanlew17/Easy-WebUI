# 国际化（i18n）

> 适用范围：语言包组织、默认语言解析、字符串硬编码禁令、数字/时间格式化、中文排版规则。
> 何时读取：新增/修改任何用户可见字符串之前——**每个用户可见字符串都必须走 i18next 并同时加进两份语言包**。
> 关联需求：无（v1.0.1 现状快照）。
> 最后更新：2026-09-13
> 来源：原 prd.md §5.5 + 原 docs/impl-contract.md §9

## 1. 语言包

- `src/i18n/zh-CN.json` / `en-US.json`，键名点分层级（`chat.input.placeholder`、`settings.providers.add` …）。
- **所有面向用户的字符串禁止硬编码**，含错误提示、按钮 aria-label、确认框；提交前自查无残留。
- 标签有时已含 emoji——添加前检查，避免重复。

## 2. 默认语言与切换

- 解析顺序：Cookie（`easyui_prefs` 已解析 lang）→ 系统 locale 命中中文则 zh-CN，否则 en-US；切换后写 Cookie。
- 语言与主题等轻偏好同走 Cookie 通道（见 `./ui-liquid-glass.md` §5）。

## 3. 格式化与排版

- 数字、时间、时长一律 `Intl.*` 按当前语言格式化。
- 中文不用 italic；强调用字重/颜色。
- 错误文案三段式：发生了什么 / 可能原因 / 建议操作（详见 `./ux-guidelines.md`）。

## 4. Mock 桥演示回复

Mock 桥演示回复中英各一段，按当前语言选择（见 `../contracts/impl-contract.md` §6）。
