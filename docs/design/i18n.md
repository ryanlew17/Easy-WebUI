# 国际化

> 权威范围：双语言包、语言解析、文案归属和本地化格式化。
> 何时读取：新增或修改任何用户可见字符串之前。
> 代码事实来源：`src/i18n/zh-CN.json`、`src/i18n/en-US.json`、`src/lib/format.ts`。
> 最后更新：2026-11-22

## 1. 文案规则

- 所有用户可见字符串必须走 i18next，并同时加入 `zh-CN.json` 与 `en-US.json`，包括按钮、错误、确认框和 aria-label。
- 键名使用点分层级，如 `chat.input.placeholder`、`settings.providers.add`；不得在某个页面硬编码另一份文案。
- 添加带符号或 emoji 的文案前检查现有标签，避免重复装饰。

## 2. 语言解析

优先使用偏好中的已解析语言；未设置时，系统 locale 命中中文使用 zh-CN，否则使用 en-US。切换后立即生效并持久化，存储规则见 `./storage.md`。

## 3. 格式化与排版

数字、日期、时间和时长使用 `Intl.*` 或项目内对应的语言感知格式化函数。中文不使用 italic，强调通过字重或颜色表达。错误文案结构见 `./ux-guidelines.md`。

Mock 演示回复按当前语言选择中英文内容，契约见 `../contracts/impl-contract.md`。
