# 版本历程（Changelog）

> 适用范围：版本主题摘要。完整 Release 说明见 GitHub Releases（纯英文）；发布规范见 `./release.md`。
> 最后更新：2026-11-25

| 版本 | 主题 | 要点 |
| --- | --- | --- |
| v1.1.0 | 视觉系统与渲染基线 | React 19；共享应用骨架、四档圆角与统一控件；深浅主题材质、焦点、浮层、滚动与空态系统重构；i18next 26（修复 GHSA-6jcc-5g8w-32mx）；完整功能、视觉和性能验收 |
| v1.0.4 | 安全与工具链 | Node.js 开发基线收紧至 26.13.1 及以上的 26.x；Electron 45.4.1（Node 24.22.3 / Chromium 156）；统一 npm 与直接脚本版本预检；minimatch 审计清零 |
| v1.0.3 | 安全、性能与升级体验 | zod 4 / TypeScript 7 / Tailwind 4 / Vitest 5；GitHub Release 摘要支持 GFM 与白名单安全 HTML 并按需加载；优化首屏加载、流式渲染、消息树和备份性能；强化基准隔离与分支恢复；生产依赖审计清零 |
| v1.0.2 | 安全与运行时 | Electron 45.2.1 / Node 24.22.1；safeStorage 异步迁移且兼容旧密文；修复生成并发竞态与窗口缩放时序；强化备份清单、模型上限及流式/后台异常处理 |
| v1.0.1 | 质量与稳定 | 浮层模糊 portal 根治、气泡与焦点对齐、分支删除路径恢复、窗口尺寸记忆、一键截图管线 |
| v1.0.0 | 对话体验大版 | UI/动效大修；树形分支、生成统计、思考开关、上下文计量、程序图标 |
| v0.1.2-beta | 升级链路验证 | 在线升级 E2E 实测 |
| v0.1.1 | 数据与外观 | 数据目录体系（便携/安装/自定义 + 迁移抢救）、外观定制、InfoTip、关于页 + 在线升级 |
| v0.1.0 | MVP | 平台管理、三协议适配、流式对话、参数面板、上下文裁剪、密钥加密、备份、液态玻璃 UI、双语、Win 安装包 |

兼容性：v1.0.2 起备份密码限制为 8–32 位。此前使用超过 32 位密码创建的备份需先用旧版本恢复，再以合规密码重新导出。

开发环境：v1.0.4 起 Node.js 要求 `>=26.13.1 <27`，Electron 45.4.1 内嵌 Node 24.22.3；v1.1.0 起浏览器构建目标为 Chrome／Edge 139+、Firefox 128+、Safari 16.4+（构建目标不等于对应浏览器均已完成实测）。TypeScript 构建由 `@typescript/native` 提供 7.0.2，`typescript` 保留 5.9 以满足旧 peer 依赖。
