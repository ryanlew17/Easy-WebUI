## 1. 交付成果

### 视觉系统与页面骨架

- 聊天与设置共享 `AppFrame`、15rem 导航、52rem 内容列和可拖宽检查器。容器查询在 64rem 以下切换实色覆盖栏，CSS 与 JS 共用 `--inspector-layout`，界面字号变化不会破坏断点一致性。
- 深浅主题共用四档圆角、squircle 渐进增强、语义排版和材质令牌。真圆与胶囊保持圆形端点，光学伪元素继承宿主轮廓。
- 内容层保持开放，不为分组重复叠加卡片。输入坞是强玻璃锚点，顶栏与功能浮层按职责使用不同强度的材质；同屏模糊层不超过 5。
- 应用缩放 50%–250%、浏览器缩放 67%–200%、界面字号 10–24px 下，导航、消息、输入坞、检查器和设置内容保持可用。长草稿通过动态底部安全区避免遮挡。

### 控件、焦点与可访问性

- 普通模式不使用统一的蓝色焦点外框。文本输入和输入坞使用内嵌边缘光，普通控件使用内高光与内发光，实色按钮和开启控件使用 `--on-accent` 反色内高光。
- 会话焦点合并到整行；Chromium 自动纳入 Tab 序的可滚动代码块具有同等焦点反馈。forced colors 使用 CanvasText、真实系统色边界和 Highlight 轮廓。
- 正文与关键文字达到 4.5:1，控件边界和焦点指示至少 3:1。浅色当前会话行的焦点实测最低 4.01:1，代码灰底为 4.21:1。
- Modal 在开发与生产模式下均保持打开焦点，关闭后返回原触发控件。检查器分隔条支持键盘调整，设置导航在高度不足时独立滚动。

### 对话、浮层与设置

- Generate 是单一玻璃胶囊；Think、上下文用量和圆形发送/停止形成统一底行。滚动渐隐、指针高光、消息统计详情、开放空态和选择模式遵循统一材质规则。
- 分支返回只恢复激活路径，不改动消息树；回到原叶或删除原叶子树后入口自动失效。
- Toast 位于顶栏下方并按工作区居中，随工作区和缩放变化重定位。默认三栏不遮挡检查器、输入坞或 Generate；显式覆盖栏或高度不足时允许短暂覆盖。
- 平台模型勾选、手动添加、预设、备份和 About 使用共享字段体系。长双语选项与长 URL 不隐藏关键语义，也不覆盖相邻操作。

## 2. 材质决策

**交付版本使用完整 CSS 材质，不启用真实折射。** `GlassMaterialProvider` 默认输出 `fallback/filter-budget`，保持零折射表面、零地图和零 GPU 材质缓存；首帧、降低透明度、无 WebGPU 和引擎失败均使用可读降级。

vendored 引擎、适配层、MIT 许可证、本地 Worker、data: 地图和懒加载产物继续保留，页面不得直接调用上游 API。真实折射未达到本需求的性能预算，不属于已交付效果；未来启用必须重新完成生产 `file://`、CSP、Worker、表面生命周期、视觉和交替性能验收。

## 4. 性能结论

最终比较使用同一 Chrome、相同数据与视口、三构建五轮交替 A/B。基线为重构前 `0123dba`；绝对耗时只代表本机采样，不用于替代相对比较。

| 指标 | 中位数的中位数 | 逐轮配对中位数 | 结论 |
| --- | ---: | ---: | --- |
| 主线程 ScriptDuration | +2.94% | +2.67% | 通过 10% 门槛 |
| 主线程 TaskDuration | +4.78% | +4.78% | 通过 10% 门槛 |
| GPU ScriptDuration | +4.14% | +3.72% | 通过 10% 门槛 |
| GPU TaskDuration | +9.56% | +6.73% | 通过，但余量很小 |

**性能约束：GPU TaskDuration 的中位数口径距 10% 上限仅 0.44 个百分点，且单轮存在明显噪声。** 后续修改样式、布局或渲染路径时，必须重新执行至少五轮交替 A/B，并结合逐轮配对结果判断；不得沿用本次结论或用不同时间的绝对值宣称无回退。

既有绝对门槛保持通过：交互 p95 最慢 20.7ms，冷启动可交互与材质就绪约 0.5s，静置 Paint=0，GC 后内存无单调增长。

## 5. 边界

本需求未改变主进程业务契约、IPC、协议适配器、密钥、消息树数据结构或 Mock API；未引入 Base UI、GlassMenu、远程视觉资源、移动端支持或新的持久缓存。

主进程仅将响应头 CSP 与 `index.html` 的 meta 对齐到同一个首帧脚本哈希（`script-src 'self' 'sha256-…'`，未启用 `unsafe-inline`），用于修复 REQ-2026-005 记录的响应头拦截内联启动脚本问题；该哈希由 `tests/webcontents-guard.test.ts` 按实际脚本重算校验。CSS 构建目标随 `corner-shape` 提升至 Chrome／Edge 139+，Chrome 138 保留普通圆角回退验证。
